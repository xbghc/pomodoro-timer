# v2.1.1 · English interface

Pomodoro Timer now uses English throughout its windows, menus, tooltips, reminders, accessibility labels, validation messages and file-error messages.

## Changes

- English-only app localization, including native settings and record-editing controls.
- English dates and 24-hour times, while keeping your local time zone and scheduling calendar.
- English names for the built-in schedule templates. Existing template identifiers, schedules and activity history remain intact; custom template names remain as entered.
- Concise English text for the compact timer and menu bar, with full details available in tooltips and the calendar window.

## Download and install

- Apple Silicon: `PomodoroTimer-2.1.1-macos-arm64.zip`
- Intel Mac: `PomodoroTimer-2.1.1-macos-x86_64.zip`
- Quit the previous version, unzip the download and replace `PomodoroTimer.app` in Applications.
- Requires **macOS 13.0 or later**. No data migration is needed.
- Download `SHA256SUMS` and both ZIP files, then run `shasum -a 256 -c SHA256SUMS` to verify them.

The app is **ad-hoc signed and not notarized**. If macOS blocks the first launch, verify the source and checksum, then follow [Apple's instructions](https://support.apple.com/en-us/102445).

## Verification

The [English UI verification run](https://github.com/xbghc/pomodoro-timer/actions/runs/40851510330) passed all 70 tests on Linux, Apple Silicon and Intel. Both Mac builds passed native compilation, linking, packaging, signature and deployment-target checks. Each architecture produced 14 real UI screenshots with Chinese language preferences supplied only to the app process; the inspected interface and native date controls remained in English. All screenshot checksums were verified, with the full Apple Silicon set and key Intel windows visually reviewed.

The release workflow requires Linux and both Mac architectures to pass the core tests and native builds. Both packages are checked after extraction, and release assets are downloaded and verified before publication. Full manual testing on macOS 13, across Spaces, and with multiple displays is still pending.
