# v2.0.0 · Work and breaks

This release rewrites the app as a **native macOS SwiftUI application**, with an AppKit drawer that opens when hovering at the desktop edge. A Windows version is no longer provided.

## Download and install

- Apple Silicon (M series): `PomodoroTimer-2.0.0-macos-arm64.zip`
- Intel Mac: `PomodoroTimer-2.0.0-macos-x86_64.zip`
- Both ZIPs contain the complete `PomodoroTimer.app`. Unzip it, move it to Applications and open it. Use the menu bar or the handle on the right edge of the desktop.
- Requires **macOS 13.0 or later**. Running the packaged app does not require Xcode or Swift; building from source requires Swift 6.0 / Xcode 16.0 or later.
- Download `SHA256SUMS` and both ZIP files, then run `shasum -a 256 -c SHA256SUMS` in the download directory to verify integrity.

The app is **ad-hoc signed**, has no Developer ID signature and is **not notarized by Apple**. Gatekeeper may block the first launch. Verify the source and checksum, then follow [Apple's instructions for opening the app](https://support.apple.com/en-us/102445). This release does not change system security settings or provide scripts to disable Gatekeeper or remove quarantine attributes.

## Changes

- A dynamic work schedule handles work, breaks and idle separately. Only actual work and breaks count toward statistics. Defaults are 30 minutes of work and 5 minutes of break.
- Work continues after a reminder until a break or stop ends the record. Extending focus for one hour recalculates the reminder from the click without splitting the continuous record. Fixed schedule ends take priority.
- Break completion enters idle until work is started manually; the next scheduled work start can take over.
- JSON defines templates and weekday mappings. In-app template selection affects today only; future plans are edited through JSON.
- The history calendar separates read-only plans from actual records. Actual work/break records can be added, edited or deleted, and data does not clear automatically.
- Native edge drawer and gentle reminders. **Full-screen breaks have been removed**; regular break timing remains.
- Launch, sleep and exit do not backfill offline time. Crash recovery ends at the last successfully saved checkpoint.

This is a separate native implementation: **it does not migrate, read or delete old Electron data**. New data lives in `~/Library/Application Support/PomodoroTimerNative/`.

## Verification and known limits

- Release publication requires all 58 core tests to pass on Linux, Intel Mac and Apple Silicon Mac, together with real SwiftUI/AppKit compilation, linking and release packaging.
- Both architectures verify executable permissions, app signatures and binary architecture after ZIP extraction. Uploaded assets are downloaded and checked against SHA-256 before publication.
- The native app was launched on both macOS runner architectures, with screenshots of work, breaks, idle, calendar, templates and the drawer on one display: [real UI verification](https://github.com/xbghc/pomodoro-timer/actions/runs/39727287792). The application source matches this release; only release automation and documentation were added afterward.
- **Full manual acceptance remains pending** on macOS 13 and for Spaces, other apps' full-screen spaces, sustained keyboard focus, multiple displays and system sleep/wake. Passing deployment-target checks and CI does not establish acceptance of those interactions.
