# v2.0.0 · 工作与休息

本次重写为 **macOS 原生 SwiftUI 应用**，使用 AppKit 实现桌边悬停抽屉，不再提供 Windows 版本。

## 下载与安装

- Apple Silicon（M 系列）：`PomodoroTimer-2.0.0-macos-arm64.zip`
- Intel Mac：`PomodoroTimer-2.0.0-macos-x86_64.zip`
- 两个 ZIP 均包含完整 `PomodoroTimer.app`。解压后放入“应用程序”，打开应用；入口在菜单栏和桌面右侧把手。
- 最低运行系统：**macOS 13.0**。运行已编译应用不需要安装 Xcode 或 Swift；源码构建需要 Swift 6.0 / Xcode 16.0 或更新版本。
- 同时下载 `SHA256SUMS` 和两个 ZIP，在下载目录运行 `shasum -a 256 -c SHA256SUMS` 验证文件完整性。

应用使用 **ad-hoc 签名**，没有 Developer ID 签名，**未经过 Apple 公证**。首次打开时 Gatekeeper 可能阻止运行；请先核对来源和校验和，再参照 [Apple 官方打开应用说明](https://support.apple.com/en-us/102445)。此发布不修改系统安全设置，也不提供关闭 Gatekeeper 或移除隔离属性的脚本。

## 主要变化

- 动态工作日程：工作、休息、等待分开处理，仅实际工作和休息参与统计。默认工作 30 分钟、休息 5 分钟。
- 工作提醒到点仍保持工作；真正开始休息才结束工作记录。“再专注 1 小时”从点击时刻重算提醒，不拆分连续记录。固定时段结束优先。
- 休息结束进入等待，由用户手动开始工作；下一固定工作起点按日程接管。
- JSON 配置模板和星期映射；应用切换模板仅作用于当天。未来计划只能通过 JSON 编辑。
- 历史日历区分只读计划和实际记录，支持补录、修改和删除实际工作/休息记录；数据不会自动清空。
- 原生桌边抽屉和温和提醒；**全屏休息功能已移除**，保留普通休息计时。
- 启动、休眠及退出不补记离线时间；异常恢复只到最后成功保存的检查点。

这是独立的原生版本：**不提供旧版数据迁移或兼容功能，不读取或删除旧 Electron 数据**。新数据位于 `~/Library/Application Support/PomodoroTimerNative/`。

## 验证范围与已知限制

- 发布流程要求 Linux、Intel Mac、Apple Silicon Mac 的全部 58 项核心测试通过，完成真实 SwiftUI/AppKit 编译、链接和 release 打包。
- 两种架构均验证 ZIP 解压后的可执行权限、应用签名和二进制架构；上传后重新下载并验证 SHA-256，再公开 Release。
- 此前已在两种 macOS runner 中实际启动本次原生实现，捕获工作、休息、等待、日历、模板和单屏抽屉截图：[真实 UI 验证](https://github.com/xbghc/pomodoro-timer/actions/runs/39727287792)。这些截图中的应用代码与本次发布相同，后续只新增发布自动化和文档。
