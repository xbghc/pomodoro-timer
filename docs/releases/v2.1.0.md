# v2.1.0 · 紧凑计时界面

根据新的设计稿重做计时小窗、桌边抽屉、菜单栏面板和设置，日历与记录保留在独立窗口。

## 主要变化

- 360×190 的计时小窗与抽屉：灰白底、细体大数字、工作红与休息绿，以及底部进度条。
- 菜单栏显示实时倒计时和进度图标，点击展开 248 pt 宽计时面板，可操作计时并打开日历、设置或退出。
- 独立的 480×520 设置窗，集中显示默认时长、今日模板、JSON 配置与本地数据入口。菜单栏倒计时可隐藏，偏好在重启后保留。
- 工作倒计时遵守提醒与固定截止；提醒后显示 `+` 超时量并继续累计工作。休息倒计时包含下一固定日程的接管时间。
- 等待时点击播放开始工作，活动中点击停止结束当前记录，旁边按钮切换到休息或工作。原有三种状态不变；未新增暂停续接、四轮长休或全屏休息。
- 小窗右键菜单保留临时时长、再专注和日历入口；`⌘0` 打开小窗、`⌘1` 打开日历、`⌘,` 打开设置。图标按钮提供中文无障碍名称与悬停说明。

本次升级沿用 v2.0.0 的工作模板、活动数据格式和保存路径，不需要数据迁移。默认工作提醒仍为 30 分钟、休息 5 分钟，未来日程与默认时长继续通过 JSON 修改。

## 下载与安装

- Apple Silicon（M 系列）：`PomodoroTimer-2.1.0-macos-arm64.zip`
- Intel Mac：`PomodoroTimer-2.1.0-macos-x86_64.zip`
- 退出旧应用后解压，将 `PomodoroTimer.app` 替换到“应用程序”，重新打开。
- 最低运行系统为 **macOS 13.0**；运行安装包不需要 Xcode 或 Swift。
- 下载 `SHA256SUMS` 和两个 ZIP 后，在下载目录运行 `shasum -a 256 -c SHA256SUMS` 校验。

应用使用 **ad-hoc 签名，未经 Apple 公证**。首次打开如遇系统拦截，请先核对来源和校验和，再参照 [Apple 官方说明](https://support.apple.com/en-us/102445)。
