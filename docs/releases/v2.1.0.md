# v2.1.0 · Compact timer interface

The timer window, edge drawer, menu bar panel and Settings have been redesigned from the new mockup. Calendar & History remains in a separate window.

## Changes

- A 360×190 timer and drawer with a light gray background, large thin digits, red work and green break states, and a bottom progress line.
- A live menu bar countdown and progress icon. Clicking opens a 248 pt timer panel with timer controls and entries for the calendar, Settings and Quit.
- A separate 480×520 Settings window for default durations, today's template, JSON configuration and local data. The menu bar countdown can be hidden, and the preference survives restart.
- Work countdowns respect both reminders and fixed deadlines. After a reminder, `+` overtime appears while work keeps accumulating. Break countdowns include takeover by the next scheduled block.
- Play starts work while idle; Stop ends the current record during an activity. The adjacent button switches to a break or work. The original three states are preserved; pause/resume, long breaks after four rounds and full-screen breaks were not added.
- The timer's context menu retains custom duration, extended focus and calendar actions. `⌘0` opens the timer, `⌘1` opens the calendar and `⌘,` opens Settings. In this version, icon buttons have Chinese accessibility labels and hover descriptions; English localization is introduced in v2.1.1.

This update retains v2.0.0 schedule templates, activity formats and storage paths without data migration. Defaults remain a 30-minute work reminder and 5-minute break. Future schedules and default durations are still configured through JSON.

## Download and install

- Apple Silicon (M series): `PomodoroTimer-2.1.0-macos-arm64.zip`
- Intel Mac: `PomodoroTimer-2.1.0-macos-x86_64.zip`
- Quit the old app, unzip the download, replace `PomodoroTimer.app` in Applications and reopen it.
- Requires **macOS 13.0 or later**; running the package does not require Xcode or Swift.
- Download `SHA256SUMS` and both ZIP files, then run `shasum -a 256 -c SHA256SUMS` in the download directory.

The app is **ad-hoc signed and not notarized by Apple**. If the system blocks the first launch, verify the source and checksum, then follow [Apple's instructions](https://support.apple.com/en-us/102445).
