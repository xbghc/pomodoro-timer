# Activity v2 发布前验收

本文件是待执行的人工验收步骤，不代表对应项目已在实机通过。CI 的 Windows/Linux Electron 测试使用隔离数据目录；NSIS 构建成功只证明安装包可以生成。

## 测试准备

先退出已有实例。使用测试数据目录运行应用，例如 PowerShell：

```powershell
$env:POMODORO_DATA_DIR = Join-Path $env:TEMP ('pomodoro-v2-' + [guid]::NewGuid())
npm start
```

不要在真实历史数据上测试磁盘故障或修改系统时间。旧版数据不读取、不转换、不删除；新版本不提供兼容或迁移。

## 工作流与数据

| 场景 | 操作 | 应观察到的结果 |
| --- | --- | --- |
| 自动工作 | JSON 设定一个即将开始的工作时段，应用保持运行 | 到时开始工作，记录起点不是此前等待的时间 |
| 中途启动 | 在工作时段内退出后重新打开 | 两次运行形成不同记录，退出期间不补记 |
| 提醒与延后 | 工作中选择再专注一小时，再忽略或跳过提醒 | 当前记录 ID 和起点不变，提醒按点击时间重设 |
| 固定截止 | 在固定终点前选择超出终点的专注或休息时长 | 固定终点结束当前活动，不拖到临时倒计时终点 |
| 休息结束 | 开始短休，等待结束 | 进入等待，不自动记录新的工作；手动开始或下一个固定工作时段才继续 |
| 日历编辑 | 补录、改类型、改起止时间、删除、重启 | 实际统计对应改变；只改类型不损失时间精度；其他记录不变 |
| 非法记录 | 输入未来时间、结束早于开始或重叠区间 | 明确拒绝，不改写原始记录 |
| 配置错误 | 保存无效 JSON 后重载，再修正后重载 | 失败时显示错误、保留最后有效日程，不覆盖用户文件；修正后恢复 |

## Windows 实机系统集成

- [ ] 正在工作时真正睡眠/唤醒；正在休息时再次验证。休眠期间不计入记录，恢复从当前时刻处理。
- [ ] 主窗口关闭到托盘后继续计时；托盘退出后不再运行；重启没有重复活动。
- [ ] 多显示器、不同比例缩放、拔插显示器和虚拟桌面切换；提醒不抢焦点，休息遮罩覆盖正确，临时让开 30 秒不停止休息计时。
- [ ] 系统通知允许/关闭、专注助手开启/关闭；应用内提醒仍可操作，声音开关效果符合设置。
- [ ] 登录启动开关、注销后登录；关闭开关后不再随登录运行。
- [ ] 测试安装包的安装、启动、退出与卸载。测试包与正式产品使用相同应用标识，避免覆盖日常使用环境；优先使用测试虚拟机。
- [ ] 自动更新在受控发布渠道中的下载、重启安装和失败处理。不要为验证而发布正式 Release。

## 故障保护

时钟回退保护同时覆盖自动记录和手工新增/修改的记录；删除或缩短记录后重新计算保护边界。处于系统暂停或存储错误暂停时，写操作被拒绝，历史仍可读取，不允许通过重载日程或切换模板绕过暂停。

磁盘故障、异常进程退出和修改系统时间只在隔离环境中测试。活动检查点每五秒保存一次，异常退出不恢复最后检查点之后的未知时间。
