# 番茄钟 · Activity v2

按工作日程运行、记录真实工作与休息时间的 Electron 桌面工具。此分支正在替换旧版番茄循环，尚未发布新版安装包。

## 使用方式

工作时段开始时自动进入工作；在时段中途启动应用，从启动时刻开始记录，不补记之前的时间。默认 50 分钟后提醒休息，但提醒不会结束工作，也不会强制进入休息。跳过提醒后，一小时后再次提醒。

「接下来专注」只重设提醒时间。例如 10:00 开始工作，10:20 选择再专注一小时，11:20 才提醒；直到实际休息或结束活动前，始终是一条连续工作记录。固定工作时段的终点优先于延后提醒。

休息结束后进入等待，等待不计入任何统计，准备好后手动开始工作。下一个固定工作时段的起点仍会自动开始工作。主窗口关闭后留在托盘运行；托盘「退出」才结束应用。

主界面提供当前活动控制、按日查看的计划/实际双栏日历、历史补录和编辑、当天模板选择、浅色/深色主题。实际记录不能位于未来、互相重叠或覆盖正在进行的活动；编辑当前活动前应先结束它。每日统计按该日边界截取跨日记录，只统计实际记录和当前活动，不统计计划或等待。

休息遮罩提供外部复盘提示，不包含内置复盘或下一步规划表单。遮罩可以临时让开 30 秒，休息计时不中断。

## JSON 工作模板

点击「打开 JSON」，在外部编辑器修改 `schedule.json`，然后点击「重新加载」。不提供未来计划的图形化编辑器。加载失败会保留内存中最后一份有效配置；启动时配置损坏则明确报错，不静默覆盖文件。

```json
{
  "defaultTemplate": "workday",
  "weekdays": {
    "0": "off",
    "1": "workday",
    "2": "workday",
    "3": "workday",
    "4": "workday",
    "5": "workday",
    "6": "off"
  },
  "templates": {
    "workday": [
      { "start": "10:00", "end": "12:00" },
      { "start": "13:30", "end": "18:00" },
      { "start": "19:30", "end": "22:30" }
    ],
    "off": []
  }
}
```

使用系统本地时区。星期 `0` 为周日，`6` 为周六；未指定的星期使用 `defaultTemplate`。每个时段必须为同一天内的 `HH:mm`，按开始时间排列，起点早于终点，时段之间不能重叠。空数组代表没有固定工作时段。

应用内只可以覆盖**今天**的模板，选择会持久化，不修改 JSON 模板本身。计划视图由当前 JSON 和日期覆盖计算，不是历史计划的不可变快照；改变计划不会改变实际记录。

当前边界处理：固定工作时段起点优先于跨入该时段的手动休息；更换模板后仍处于工作时段内时只调整截止时间，不拆分连续工作；更换到当前没有工作时段的模板会结束当前计划内活动。计划外可以手动工作或休息，不额外设置午夜截止，进入下一个固定时段后遵循它的边界。

## 数据与生命周期

数据保存在 Electron 的 `userData` 目录中：

- `schedule.json`：用户编辑的工作模板。
- `activity-preferences.json`：默认提醒/休息时长、主题、声音、登录启动、当天模板覆盖。
- `activity-records.json`：实际工作/休息区间，长期保留，支持新增、编辑、删除。
- `activity-checkpoint.json`：当前活动最后观测时间的检查点。

退出或系统休眠会关闭当前活动；恢复后只从恢复时刻重新记录。超过两分钟的心跳间隔按可能休眠处理，保守地截断到最后观测点。运行中每五秒保存检查点，异常退出后最多可能丢失最后约五秒，绝不把离线时间补成工作或休息。稳定活动 ID 避免重复恢复同一条记录。

系统时钟回退时停止当前记录，等待时钟达到上一条记录终点再恢复自动工作，以免重复统计重叠时间。

**不兼容旧版，也不迁移数据。** 不读取、不转换、不删除旧版 `history.json`、`settings.json`、`runtime.json`。新版本历史为空是预期行为。

## 开发与验证

```bash
npm ci
npm start
npm test
```

`npm test` 使用 Node 内置测试运行器，无需启动 Electron。新增测试覆盖状态机、日程、数据校验、崩溃检查点恢复、日历统计和模拟 Electron 的 IPC/窗口/电源事件。仓库内旧模块和旧测试暂未完全清理，但新入口不调用旧循环。

真实 Electron 冒烟测试使用独立临时数据目录，不接触正常应用数据：

```bash
node scripts/smoke-activity.js
# 无显示器的 Linux 环境：
xvfb-run -a node scripts/smoke-activity.js
```

测试验证真实 preload IPC、主窗口、休息遮罩、等待状态、日历补录、模板切换与磁盘持久化。`POMODORO_DATA_DIR` 仅用于指定独立测试/开发数据目录。GitHub Actions 对 PR 执行 Windows/Linux 单元测试及 Linux Electron 冒烟测试。

发布前仍需完成 Windows 实机验证：安装与更新、真正的休眠/唤醒、多显示器与虚拟桌面、通知和遮罩冷启动。旧 Storybook 示例与旧 `scripts/smoke.js` 尚未迁移到 v2，不应用于验收新界面。此分支没有自动发布或合并到 `main`。
