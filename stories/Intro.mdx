# Activity v2

此预览直接使用新版应用的 HTML、CSS 和渲染代码，IPC 由内存示例替代。不会读取用户数据，不会打开系统文件，不会启动自动更新。

## 界面状态

工作与活动日历、等待、空记录、轻提醒、休息遮罩、存储错误暂停。工具栏可以切换浅色和深色；记录编辑和统计变化可以在预览内演示，刷新后重置。时间冻结在示例时刻，不代表真实计时测试。

## 业务规则

提醒不是活动切换。调整接下来专注的时间不会拆分当前工作记录；固定工作时段终点优先。休息结束后停在等待，等待不计入统计。未来工作计划只在外部 JSON 中编辑，应用内只切换今天的模板。实际记录可以新增、编辑、删除，计划不参与统计。

## 验证边界

Storybook 只用于检查界面。真实 preload IPC、计时、窗口、记录持久化和重启流程由 `npm run test:smoke` 验证；工作日程和生命周期规则由 `npm test` 验证。
